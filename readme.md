# AutoHour

[1hour.ai](https://1hour.ai)의 학습과정을 자동으로 진행해주는  브라우저 확장 프로그램입니다.

## 주의사항

**교육용 및 학습용으로만 사용해 주세요**

- 이 프로그램을 사용함으로써 발생하는 모든 피해나 손실은 사용자 본인의 책임입니다.
- **[1hour.ai](https://1hour.ai)측의 삭제요청이 있을 경우, 즉시 삭제됩니다.**
- 사이트 UI나 데이터 구조 변경에 따라 일부 기능이 동작하지 않을 수 있습니다.
- 모든 문의는 `shaeui@proton.me` 로 부탁드립니다.
- 상업적 사용시 출처를 명시해 주세요.
> 메일확인이 늦더라도 양해 바랍니다.

## 주요 기능

- 일반 단어 선택 문제의 정답을 분석하고 선택합니다.
- 퀴즈 선택형 및 다중 선택형을 처리합니다.
- 플래시카드 모드에서 `알아요` 버튼을 처리합니다.
- 그외 여러가지 과제를 지원합니다.

## 설치

### PC

1. 이 프로젝트를 [내려받거나](https://github.com/xp1hed/AutoHour-Public/archive/refs/heads/main.zip) 복제합니다.
2. 주소창에 `chrome://extensions`를 엽니다.
3. 우측 상단의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 선택합니다.
5. 이 프로젝트의 루트 폴더를 선택합니다.
6. [1hour.ai](https://1hour.ai)의 학습 페이지를 열고 확장 아이콘을 누릅니다.
7. **Enable Auto Solver**를 눌러 실행하거나, 다시 눌러 중지합니다.
8. 제대로 작동하지 않는 경우 페이지 새로고침 또는 프로그램을 재시작해주세요.

### Android

1. 확장 프로그램을 [다운로드](https://github.com/xp1hed/AutoHour-Public/releases/download/1.0.3/AutoHour-1.0.3.crx) 받습니다.
2. [Kiwi Browser](https://github.com/kiwibrowser/src.next/releases/tag/14310011181)를 다운로드 받습니다. ([Galxy 기준 다운로드](https://github.com/kiwibrowser/src.next/releases/download/14310011181/com.kiwibrowser.browser-arm64-14310011181-github.apk))
3. 우측 상단의 메뉴버튼을 누른후 확장프로그램 항목을 선택합니다.
4. 우측 상단의 **개발자 모드**를 활성화 합니다.
5. 다운로드한 .crx 파일을 추가합니다.
6. [1hour.ai](https://1hour.ai)의 학습 페이지를 열고 확장 아이콘을 누릅니다.
7. **Enable Auto Solver**를 눌러 실행하거나, 다시 눌러 중지합니다.
8. 제대로 작동하지 않는 경우 페이지 새로고침 또는 프로그램을 재시작해주세요.

### iOS

1. 확장 프로그램을 [다운로드](https://github.com/xp1hed/AutoHour-Public/releases/download/1.0.3/AutoHour-1.0.3.crx) 받습니다.
2. [Orion Browser](https://apps.apple.com/us/app/orion-browser-by-kagi/id1484498200)를 다운로드 받습니다.
3. 다운로드 받은 .crx 파일을 `나의 iPhone/Orion/Extensions`에 추가합니다.
3. 우측 하단의 메뉴버튼을 누른후 Extensions을 눌러 + 를 눌러 `Install from File`을 합니다.
4. `나의 iPhone/Orion/Extensions`에 있는 .crx 파일을 선택합니다.
5. [1hour.ai](https://1hour.ai)의 학습 페이지를 열고 확장 아이콘을 누릅니다.
6. **Enable Auto Solver**를 눌러 실행하거나, 다시 눌러 중지합니다.
7. 제대로 작동하지 않는 경우 페이지 새로고침 또는 프로그램을 재시작해주세요.

#### Kiwi, Orion 브라우저 쓰는이유: 개인이 만든 확장프로그램 사용이 가능한 브라우저가 이런것 밖에 없음

#### 테스트한 환경

PC Chrome / iPhone Orion / Android Kiwi

## 사용자 지원

```
Q. 데스크탑 환경에서 작동하지 않아요
A. 프로그램 새로고침 또는 1hour 페이지를 새로고침하세요

Q. 모바일 환경에서 작동하지 않아요
A. 설정에서 브라우저 호환성/Google Chrome 이 활성화 되어있는지 확인하세요

Q. 프로그램이 작동하지 않아요
A. 프로그램이 최신버전인지 확인하세요

Q. 그대로 프로그램이 작동하지 않아요
A. 해당 로그와 스크린샷을 함께 메일로 보내주세요, 빠른시일내 수정하겠습니다.
```
